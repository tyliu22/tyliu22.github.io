Logistic regression#

Logistic regression models the relationship between the independent variables (features) and the dependent variable (output) by estimating probabilities using the logistic (sigmoid) function. The sigmoid function maps any real-valued number to a value between 0 and 1, making it suitable for binary classification.

The sigmoid function is defined as: $$ \sigma(z) = \frac{1}{1 + e^{-z}} $$ The output of the sigmoid function represents the probability that the input ( x ) belongs to the positive class.

Logistic regression uses the log-loss (cross-entropy) as the cost function, which is defined as:

$$ J(w, b) = - \frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(\hat{y}^{(i)}) + (1 - y^{(i)}) \log(1 - \hat{y}^{(i)}) \right] $$

where m is the number of training examples, $y^{(i)}$ is the actual label, and $\hat{y}^{(i)}$ is the predicted probability.

  1. Why the LR use the logit (log-odds) function instead of modelling the probabilities directly? The logit function is the $$\text{logit}(p) = \log \left( \frac{p}{1-p} \right)$$

    • Direct modelling of probabilities can lead to issues because probabilities are bounded (0 to 1), while linear function are unbounded;
    • The logit function transforms the probability to the log-odds scale, which ranges from -inf to inf , making it suitable for linear modelling.

  2. If the model is underperforming, what should you do?

    • Data augmentation: SMOTE
    • Feature engineering: add non-linear feature; normalize or scale the features
    • Regularization
    • Hyperparameter tuning
    • Class imbalance

Decision tree#

A decision tree is a supervised learning algorithm used for classification and regression tasks. It splits the data into subsets based on feature values.

  • how it works: First, select the best feature to split the data; Second, it recursively splits the dataset into subsets; Finally, all data in a node belong to the same class or further splitting doesn’t improve results.
  • splitting criteria (impurity measures)
    • Gini impurity (classification): measure how often a randomly chosen element would be incorrectly labelled. $$Gini = 1 - \sum p_i^2$$
    • entropy (classification): Measures the level of disorder or impurity in a node. $$Entropy = - \sum p_i \log_2 p_i$$
    • Mean squared error (regression): measures variance within the node.

Ensemble tree models#

Type of ensemble models#

  1. Bagging (Bootstrap aggregating)
    • Trains multiple models in parallel on different subset of data (sampled with replacement)
    • Results are averaged (regression) or use majority voting (classification)
    • Random forest
  2. Boosting - Gradient boosting
    • Models are trained sequentially, with each model correcting the errors of the previous one (Learn from the residual)
    • Assigns higher weights to the misclassified data
    • Gradient boosting, XGBoost, LightGBM
  3. Stacking
    • Combines predictions from multiple models (meta-learner) to make a final prediction
    • More complex but can yield strong performance

Ensemble tree models#

  1. Random forest

    • Each tree is trained on a random subset of data and a random subset of features;
    • The final prediction is the average or majority voting of all trees.
    • Advantages:
      • Reducing overfitting; Handles missing value and outliers well

  2. Gradient boosting

    • Builds trees sequentially
    • Each tree corrects the residual errors of the previous trees
    • Focuses more on hard-to-predict data points by increasing their weight
    • Advantages:
      • More accurate than random forest, especially on complex datasets
    • Disadvantages:
      • Prone to overfitting if the number of trees is too large
      • sensitive to noisy data

  3. XGBoost

    • Regularized Gradient Boosting – Improves standard GBDT by adding L1/L2 regularization.
    • Key features:
      • Use the level-wise growth
      • Pre-pruning: during tree construction. This stops the tree from growing when the gain (information improvement) from splitting is too small
      • Build-in cross-validation
      • Handles sparse data and missing values
      • Supports parallel training

  4. LightGBM

    • Designed for speed and scalability on large dataset
    • Key features:
      • Post pruning: after they are fully grown by removing leaves that don’t meet the minimum number of data points.
      • use the leaf-wise growth
      • feature binning, growing trees faster and deeper
    • handle categorical feature natively

How to avoid overfitting#

  • Regularization
  • Early stopping
  • Max depth
  • Learning rate
  • Subsampling (feature fraction)
  • Pruning

K-means#

K-means is an unsupervised learning algorithm used for clustering data into k groups based on feature similarity. It minimizes intra-cluster variance (distances between points and their cluster centers).

  • How it works:
    • Step 1: initialise k cluster centers randomly
    • Step 2: assign data points to clusters
    • Step 3: update the centers based on the mean of all points in the cluster
    • Step 4: repeat until convergence

  1. Loss function

    • within-cluster sum of squares (WCSS)$$J = \sum_{i=1}^{k} \sum_{x \in C_i} | x - \mu_i |^2$$

  2. How to select the number of K

    • Elbow method
      • Principle: suppose the $k^\star$ is the actual number of clusters,
        • if the $k$ is smaller than $k^\star$, then when increase the $k$, the performance will be improved significantly
        • if if the $k$ is larger than $k^\star$, then when increase the $k$, the performance will be improved slightly
        • Plot the loss with different $k$, find the turning point
    • Gap Statistic
      • The Gap Statistic compares the clustering performance of K-means on the real data to that of randomly generated reference datasets. The optimal kkk is where the gap between the two is largest.
      • The idea is to identify the point where the clustering of the actual data significantly outperforms random clustering.

KNN (K nearest neighbour)#

K-Nearest Neighbors (KNN) is a non-parametric, lazy learning algorithm used for classification and regression tasks. It predicts the output by finding the $k$-nearest data points to a given query point and uses their labels (for classification) or values (for regression).

  1. How to select the number of $k$
    • small $k$: high variance (overfitting)
    • large $k$: high bias (underfitting)
    • use the cross-validation to select the best $k$ or elbow method

SVM (Support Vector Machine)#

It works by finding the optimal hyperplane that best separates data points of different classes in a high-dimensional space. SVM constructs a decision boundary (hyperplane) that separates data points by maximizing the margin.

  • SVM constructs a decision boundary (hyperplane) that separates data points by maximizing the margin.
  • The data points closest to the hyperplane are called support vectors.
  • SVM tries to maximize the distance between the hyperplane and these support vectors, improving model generalization.

  1. Why kernels:

    • Linear model (SVM, LR) are limited to data
    • Map data into a higher-dimensional space
    • Direct transformation to higher dimensions is computationally expensive
    • Kernel compute the inner product in the transformed space without performing the transformation explicitly, which is called kernel trick – it implicitly computes the dot product in high dimensions.

  2. Different kernels?

    • linear, rbf, polynominal kernels
      • linear: linearly separable data
      • polynominal:
        • Data has non-linear relationships but is still smooth and continuous.
        • Degree ddd controls the complexity of the boundary.
      • rbf:
        • Data is not linearly separable in its original space.
        • RBF kernel maps data into infinite-dimensional space.
        • Works well when the relationship between labels and features is highly non-linear.

  3. How to select kernels?

    • start from simple Kernel
    • Try RBF next and use Polynomial kernel for feature interactions
    • Grid search and cross validation for hyper-parameter tuning

PCA (Principle Component Analysis, USL)#

PCA identifies the directions (principal components) that maximize the variance in the data. High variance indicates features that carry the most information. Reduce dimensionality.

  • Standardize each feature to (0 to 1); PCA is sensitive to scaling. Features with larger ranges dominate variance.
  • Calculate the Covariance Matrix; Measures how features vary with respect to each other.
  • Perform eigen decomposition: eigenvector and eigenvalues
  • select top $k$ principle component
  1. The limitation of PCA
    • Loss of interpretability; sensitive to outliers, and the assumption of linear relationships in data
  2. Can PCA handle non-linear data?
    • standard PCA cannot handle non-linear data. Try kernel PCA for non-linear cases

LDA (Linear Discriminant Analysis, SL)#

Unlike PCA, which maximizes variance without considering class labels, LDA maximizes class separation by finding linear combinations of features that best separate different classes.

LDA projects data onto a line that maximizes the separation between class means and minimizes variance within each class by projecting data onto a lower-dimensional space.
