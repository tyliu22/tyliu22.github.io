Evaluation metrics#

Class balance: accuracy; ROC curve Class imbalance: precision, recall, PR curve

  1. Precision
    • Definition: Measures how many predicted positive instances were actually positive.
      • Formula:$$\text{Precision} = \frac{TP}{TP + FP}$$
    • Interpretation: High precision means fewer false positives.
    • Use Case: Important when false positives are costly (e.g., disease diagnosis).
  1. Recall
    • Definition:
      Measures how many actual positive instances were correctly predicted.
    • Formula:$$\text{Recall} = \frac{TP}{TP + FN}$$
    • Interpretation: High recall means fewer false negatives.
    • Use Case: Important when false negatives are costly (e.g., cancer detection).
  1. F1 Score
    • Definition: Harmonic mean of precision and recall, balancing both.
    • Formula: $$F1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$
    • Interpretation:
      Higher F1 score means better overall performance.
  1. AUC-ROC Curve
    • Definition:
      Plots True Positive Rate (Recall) against False Positive Rate (FPR) at different thresholds.
      • True Positive Rate (TPR) = Recall
      • False Positive Rate (FPR): $$FPR = \frac{FP}{FP + TN}$$
    • Interpretation:
      - AUC ranges from 0 to 1.
      - Higher AUC = better model performance. AUC=0.5 means a random classifier
    • Use Case:
      Ideal for imbalanced datasets.
    • Random Classifier Behaviour
        • For a random classifier, the TPR and FPR increase at the same rate as the threshold changes.
      • The ROC curve will be a diagonal line from (0,0) to (1,1).
  1. Precision-Recall (PR) Curve
    • Definition:
      Plots precision vs. recall at different thresholds.
    • Interpretation:
      Highlights the trade-off between precision and recall.
    • Use Case:
      Useful when the positive class is rare (e.g., fraud detection).
    • Random Classifier Behaviour
      • In highly imbalanced datasets, a random classifier’s PR curve often appears as a horizontal line at the baseline precision value, representing the chance-level performance.

Practical problems#

  1. How to deal with overfitting?

    • Data augmentation OR resampling
    • feature selection
    • regularization: l1/l2
    • cross validation
    • early stopping
    • pruning decision tree

  2. How to deal with class imbalance?

    • Resampling (upsampling or undersampling)
    • weighted loss function
    • evaluation metrics for imbalanced dataset

  3. Explain the bias and variance trade-

    • What is bias and variance
      • Bias – Error due to overly simplistic assumptions in the model.
      • Variance – Error due to excessive sensitivity to small fluctuations in the training data.
    • Bias variance and overfitting & underfitting
    • Trade-off
      • Reducing bias increases model complexity, but may lead to overfitting (high variance).
      • Reducing variance simplifies the model, but may lead to underfitting (high bias).

  4. Cross-validation The cross validation is for reducing the risk of overfitting or underfitting. The dataset is divided into $k$-folds. The model is trained $k$ times and each time leaving out one fold for validation. - K-fold cross-validation - stratified k-fold - Similar to K-Fold, but keeps the class distribution balanced in each fold (important for imbalanced datasets). - time series cross-validation - used for time dependant data. Training is done on past data, and validation is done on the future data

  5. Data leakage Data leakage is a critical issue in machine learning where information from outside the training dataset (or future data) unintentionally influences the model during training. This leads to over-optimistic performance during training but poor generalization to unseen data. - Scaling or normalising the entire dataset before splitting into train/test sets. - Using future data to predict past events, which violates the natural order of time.

  6. What is the Curse of Dimensionality? 

    • As the number of dimensions increases, the data becomes sparse, and the distance metrics used in algorithms lose meaning, making it difficult to model and analyse.
    • The time and resources required to process data increase exponentially with dimensionality.
