Data clearing#

Handling Missing Values in Data#

Missing values can negatively impact data analysis and machine learning models. Below is a summary of the most popular approaches to handle missing data.

  1. Removal Techniques
    • Drop Rows – Remove rows with missing values.
    • Drop Columns – Remove columns with too many missing values.
    • When to Use:
      - Small amount of missing data.
      - Risk of losing information.
  1. Imputation Techniques
    • Mean/Median/Mode Imputation – Replace missing values with the column’s mean, median, or mode.
    • Forward/Backward Fill – Use previous or next values to fill missing data (time series).
    • KNN Imputation – Use K-Nearest Neighbors to estimate missing values.
    • When to Use:
      - Moderate amount of missing data.
      - Preserves data integrity without deletion.
  1. Advanced Techniques
    • Regression/Prediction Models – Use machine learning models to predict missing values.
    • When to Use:
      - Large datasets with significant missing data.
      - More accurate, computationally expensive.
  1. Handling Categorical Data
    • Mode Imputation – Fill missing values with the most frequent category.
    • Label ‘Unknown’ – Tag missing values explicitly as ‘Unknown’ or ‘Missing’.
    • When to Use:
      - Categorical features.
      - Avoids introducing biases.
  1. Choosing the Right Method
Missing Rate Recommended Approach
< 5% Mean/Median/Mode, Drop Rows
5-20% KNN, Forward Fill, Regression
> 20% Multiple Imputation, Drop Columns

Detecting Outliers in Data#

Outliers are data points that significantly differ from the majority of the data. Below is a summary of the most popular statistical and machine learning methods to detect outliers.

  1. Statistical Methods
    • Z-Score (Standard Score) - Measures the number of standard deviations a data point is from the mean.
      • Threshold: |z| > 3
      • Formula: $$z= (x - mean) / std$$
  1. Machine Learning Approaches
    • Isolation Forest - Anomaly detection algorithm that isolates outliers based on decision trees.
      - Contamination Parameter: Proportion of outliers (e.g., 0.05).
    • One-Class SVM (Support Vector Machine) - Classifies data as inliers or outliers by finding a boundary that separates normal data.
    • K-Nearest Neighbors (KNN) / Local Outlier Factor (LOF) - Detects outliers by measuring the local density deviation of a data point.
  1. Choosing the Right Method
Method Best For
Z-Score / IQR Simple datasets with low dimensionality
Isolation Forest Large datasets with complex patterns
One-Class SVM High-dimensional data
KNN (LOF) Local outlier detection

Data scaling and encoding#

Scaling and encoding are crucial preprocessing steps for preparing data for machine learning models. This ensures that numerical features are comparable and categorical data is represented numerically.

numerical feature#

Scaling and transforming numerical data ensures that the numerical size and distribution of features are consistent.

  1. normalisation:

    • Maps data into a fixed range, typically [0, 1], ensuring numerical stability and comparability.
    • min-max scaling:
      • Formula: $$x’ = \frac{x - min}{max - min}$$
      • Scales data to the [0, 1] range based on minimum and maximum values.
      • log scaling:
        • Handles wide ranges and reduces skew by applying logarithmic transformation.

  2. standardisation:

    • Maps data into a standard normal distribution (mean = 0, std = 1).
    • z-score standardisation:
      • Formula: $$z = \frac{x - mean}{std}$$
      • Transforms data into a distribution with a mean of 0 and standard deviation of 1.

  3. discretisation:

    • Converts continuous features into discrete bins, helping to handle long-tail distributions.

Use normalisation when: A fixed output range (e.g., [0, 1]) is required OR data is stable and has no extreme values.
Use standardisation when: Data contains outliers or noise.

  1. feature binning
    - Groups data into intervals or buckets.

categorical feature#

Encoding categorical data is necessary to convert non-numeric labels into numerical values for model processing.

  1. one-hot encoding:

    • Converts categories into binary indicators.
    • Each category is represented by a binary vector (e.g., 001, 010, 100).
    • Use for: Sparse, unordered categorical data.

  2. label encoding:

    • Maps categories to integer values (0, 1, 2, …).
    • Suitable for ordered features and tree-based models.

  3. ordinal encoding:

    • Maps categories to specific numbers, preserving their order.
    • Use for: Ordinal categorical data with meaningful ranking.

  4. count encoding:

    • Replaces categories with the frequency of their occurrence.
    • Pros:
      • Maintains feature relationships.
      • Provides frequency distribution.
    • Cons:
      • Can introduce bias.
      • Ineffective for large category sets.

  5. target encoding:

    • Maps categories to statistical values (e.g., mean, median of target).
    • Pros:
      • Handles high-cardinality features.
      • Preserves category information.
      • Cons:
        • Risk of information leakage.
        • Sensitive to outliers and overfitting.

Data augmentation for class imbalance#

Data augmentation techniques help address class imbalance by generating new samples for minority classes or reducing the number of samples in majority classes.

upsampling#

Upsampling increases the number of samples in the minority class to match the majority class, improving model performance on imbalanced datasets.

  1. smote (synthetic minority oversampling technique): SMOTE is a popular upsampling technique used to address class imbalance by generating synthetic data points for the minority class. Unlike simple duplication, SMOTE creates new samples by interpolating between existing samples, increasing the diversity of the data.

    how smote works:

    1. Select a Minority Class Sample: - Randomly choose a data point from the minority class.
    2. Identify k Nearest Neighbors: - Find the k-nearest neighbors of the selected sample within the minority class.
    3. Generate Synthetic Points: - Randomly select one of the k neighbors.
      - Create a synthetic data point by interpolating between the selected sample and its neighbor: $$x_{new} = x_i + (x_{neighbor} - x_i) \times \lambda$$ where ( \lambda ) is a random value between 0 and 1.
    4. Repeat Until Balance: - Continue generating synthetic samples until the desired class balance is achieved.

undersampling#

Undersampling reduces the number of samples in the majority class to balance the dataset, preventing the model from being biased toward the majority class.

  1. random undersampling:
    • Randomly removes samples from the majority class.
    • Simple and quick but may lead to information loss.
  2. nearmiss:
    • Selects majority class samples closest to the minority class for removal.
    • Focuses on boundary samples, improving class separation.

comparison of techniques#

technique purpose suitable for pros cons
smote generate synthetic minority samples imbalanced data, classification tasks increases data diversity may generate overlapping samples

Feature importance analysis#

Feature Importance Analysis - Summary#

Feature importance analysis helps identify which features contribute the most to a model’s predictions. This improves model interpretability, simplifies models, and guides feature selection.

  1. Model-Based Feature Importance
    Feature importance is derived directly from the model’s internal structure.
    • Linear Models (Linear/Logistic Regression):
      - Coefficients reflect feature importance. Larger coefficients indicate higher importance. - Use Case: Simple linear relationships.
      - Action: Drop features with near-zero coefficients (Lasso), and manage multicollinearity (Ridge).
    • Lasso Regression (L1 Regularization):
      - Shrinks some coefficients to zero, selecting the most important features.
      - Use Case: Feature selection with many irrelevant features.
      - Action: Tune regularization strength (alpha) and drop zero-coefficient features.
    • Ridge Regression (L2 Regularization):
      - Reduces the magnitude of coefficients without shrinking them to zero.
      - Use Case: Multicollinearity and high-dimensional data.
      - Action: Use when elimination is not required.
    • Tree-Based Methods (Decision Trees, Random Forest, XGBoost):
      - Measures feature importance by how much they reduce impurity (Gini or Information Gain).
      • Use Case: Non-linear models and feature interactions.
      • Action: Focus on high-importance features for refinement.
      • Feature importance can be computed by how much each feature contributes to reducing impurity (classification) or variance (regression) when used in decision splits. Feature Importance Based on Gini Impurity or Gain
        • Gini Impurity (for Classification): Measures how often a feature reduces the uncertainty (impurity) in a node across all trees.
        • Information Gain (for Regression): Measures how much the feature reduces the variance or Mean Squared Error (MSE) across all trees.
  1. Model-Free Feature Importance
    Model-free methods assess feature relevance independently of model structure, useful for black-box models.
    • Recursive Feature Elimination (RFE):
      - Recursively removes the least important features by refitting the model iteratively. - Use Case: Optimal for incremental simplification.
      - Action: Use RFE and select features based on cross-validation.
    • Permutation Importance:
      - Randomly shuffles feature values and measures the performance drop.
      - Use Case: Model-agnostic, works with neural networks and complex models.
      - Action: Use permutation_importance and eliminate features with minimal effect.
    • SHAP (SHapley Additive exPlanations):
      - Game-theory-based approach to assign feature contribution scores.
      - Use Case: Explaining black-box models globally and locally.
      - Action: Visualize SHAP plots to guide feature selection.

Feature interaction#

Feature Interaction Analysis#

Feature interaction analysis enhances model performance by uncovering relationships between features. This allows models to capture dependencies that might not be evident through simple linear approaches.

  1. Correlation Matrices for Numerical Variables
    A correlation matrix calculates pairwise correlation between numerical features.
    • Pearson’s Correlation measures the strength and direction of the linear relationship between two variables.
    • Spearman’s Correlation ranks data to capture monotonic relationships, making it robust to non-linear interactions.
      Detects collinearity and redundant numerical features by highlighting feature pairs with high correlation.
  2. Cross-Tabulation for Categorical Variables
    • Cross-tabulation constructs a contingency table to show the frequency distribution of categorical data.
    • A Chi-Square Test is applied to determine whether two categorical variables are independent by comparing observed and expected frequencies.
      Reveals dependencies between categorical features and identifies patterns of co-occurrence.
  3. SHAP Value (SHapley Additive exPlanations)
    • SHAP values are calculated using cooperative game theory, attributing contributions to each feature based on its impact on the model’s output.
    • The method generates explanations by comparing all possible permutations of features and their effects on predictions.
    • Partial Dependence Plots visualize the relationship between specific features and predictions while averaging over other features.
      Uncovers interactions in models like decision trees, gradient boosting, and neural networks by accurately reflecting feature contributions.
  4. Heatmap + Hierarchical Clustering
    Visualize relationships between features and group similar ones.
    • A heatmap displays a correlation matrix using color gradients, making it easy to spot strongly correlated features.
    • Hierarchical Clustering groups features based on their pairwise similarity, building a dendrogram that shows the clustering process.
    • Features in the same cluster exhibit similar patterns and can indicate redundancy or feature interactions.
      Detects patterns, collinearity, and clusters of interacting features, aiding in feature selection and model simplification.

Feature Multi-Collinearity (For Generalised Linear Model)#

Feature multi-collinearity occurs when two or more features exhibit a linear relationship, leading to redundancy in the model. In linear models or GLM (Generalized Linear Models), high collinearity can:

  • Inflate the variance of model coefficients.
  • Reduce the reliability of coefficient estimates.
  • Lead to unstable and less interpretable models.
  • Cause overfitting and poor generalization to new data.

Addressing multi-collinearity is essential for enhancing model performance, ensuring stability, and improving interpretability.

How to Detect Feature Multicollinearity#

1 Correlation Matrix
- Calculates pairwise correlation values between features.
- High correlation (typically > 0.7 or < -0.7) indicates potential collinearity.
- Effective for quick visualization of feature relationships.
- Useful in the exploratory data analysis (EDA) phase.
- Limitation: Does not capture multi-variable collinearity, only pairwise.

  1. VIF (Variance Inflation Factor)
    • VIF measures how much the variance of a regression coefficient is inflated due to collinearity.
    • A VIF score of 1 indicates no collinearity, while:
      - VIF between 1 and 5 suggests moderate correlation.
      - VIF above 5 or 10 signals high collinearity requiring attention.
    • VIF is preferable for detecting multi-variable collinearity, unlike correlation matrices.
Workflow for VIF in Linear or Logistic Regression#
  1. Fit the Model
    Train the linear, logistic, or generalized linear model on the dataset.
  2. Calculate VIF
    Compute VIF values for each independent variable to assess their collinearity.
  3. Inspect High VIF Identify features with high VIF values (typically greater than 5 or 10).
  4. Remove or Combine Features
    • Remove one of the highly correlated features.
    • Combine or create interaction terms to preserve information while reducing redundancy.
  5. Refit the Model
    Rerun the model using the reduced or modified feature set and check for improvements.
    • Monitor changes in VIF scores and model coefficients.
  6. Check Model Performance
    • Evaluate the model’s predictive performance on validation data.
    • Ensure that removing or modifying features results in more stable and interpretable coefficients.
    • Compare R², adjusted R², or AIC/BIC values to confirm improved model fit.

Feature Binning#

Feature binning is the process of transforming continuous numerical features into discrete intervals or “bins/buckets.” This transformation helps models like logistic regression capture nonlinear patterns more effectively.

Benefits of Feature Binning#
  • Handle Non-Linearity
    Binning can capture non-linear relationships better than using continuous features directly.
  • Reducing Outliers / Long-Tail Distribution
    By grouping extreme values into categories, binning reduces the influence of outliers, stabilizing model performance.
  • Reduce Model Complexity Simplifies the model, reduces noise effects, and increases robustness by limiting the granularity of numerical features.
Types of Feature Binning#
  1. Fixed Width Binning Divides the range of values into equal-sized bins regardless of data distribution.
  2. Quantile Binning
    Bins are created so that each bin contains an equal number of data points. This approach is useful for skewed distributions.
  3. Custom Binning Binning is performed based on domain knowledge or specific business logic, allowing for tailored intervals that reflect the nature of the data.

how to handle new feature#

  1. For Tree-Based Models (Random Forest, Decision Trees, XGBoost)

    • Tree models typically do not allow incremental retraining. The structure of the tree is fixed after training. However, here are a few workarounds::
    • Retrain the model from scratch with old and new features.
    • Use the existing model as a base learner. Train a new small tree or boosting model on the residuals/errors of the original model using the new feature.

  2. XGBoost/LightGBM Specific Approach

    • XGBoost and LightGBM allow incremental retraining using update() but only for new data, not new features.
    • Trick: Concatenate the new feature as an interaction term or use it in ensemble stacking.
